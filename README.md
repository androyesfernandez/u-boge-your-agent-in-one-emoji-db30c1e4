One emoji that stands for my AI agent: **🧠 Brain**.

The agent's whole job is thinking — reading a task, planning the steps, and
reasoning its way to a finished result. The brain says that at a glance, at
any size, with no explanation needed.

## How it works

`main.ts` (Node 22, stdlib only) writes exactly one character — 🧠, U+1F9E0,
4 bytes UTF-8, no trailing newline — to `/output/entry.txt`:

```sh
node main.ts
```
